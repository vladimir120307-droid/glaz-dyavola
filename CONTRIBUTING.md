# Contributing

Спасибо за интерес к проекту! Несколько правил, которые сделают вклад проще для всех.

## Скоуп

`Глаз Дьявола` — **OSINT-инструмент**: пассивная разведка + read-only валидация.
PR'ы, добавляющие активную эксплуатацию, brute-force, post-exploitation,
malware/C2, evasion-функционал — будут отклонены. Если есть сомнения,
посмотрите [`SECURITY.md`](SECURITY.md).

## Что мы рады принять

- Новые регекс-паттерны для секретов (с тестами!)
- Новые источники для subdomain-энумерации (без API-ключей)
- Новые fingerprint'ы для identity-провайдеров
- Расширение RU-слоя (СПАРК / Контур / ФССП / Госуслуги / RU-банки)
- Улучшения SARIF / HTML-репортов
- Документацию (на русском или английском)
- Тесты на существующие модули

## Процесс

1. Откройте Issue с описанием идеи **до** того, как пишете код — обсудим скоуп.
2. Форкните, создайте feature branch (`git checkout -b feat/my-thing`).
3. Пишите код и тесты вместе — `pytest tests/` должен проходить.
4. `ruff check glaz tests` — должен быть чистым.
5. Открывайте PR со ссылкой на Issue и кратким описанием.

## Стиль

- Python 3.10+
- Type hints везде, где это не очевидно
- `pyproject.toml` `[tool.ruff]` — единственный источник правды по стилю
- Сообщения коммитов: `<scope>: <что>` (e.g. `secrets: add Mistral API regex`)

## Тесты

```bash
pip install -e ".[dev]"
pytest -v
```

Каждый новый regex-паттерн сопровождается:
- positive-тестом (синтетический пример → ловится)
- negative-тестом, если есть риск false-positive

## Код-ревью

PR'ы ревьюится автором или мейнтейнерами. Ожидайте feedback'а в течение
нескольких дней.

## Лицензия

Открытием PR вы соглашаетесь, что ваш вклад будет под [MIT](LICENSE).
